# BHM OMT Decoder v1.0

Real-time Open Media Transport (OMT) decoder with a lightweight portable GUI interface.

---

## 🚀 Overview

BHM OMT Decoder is a C++ application designed for decoding and visualizing real-time media streams using the Open Media Transport protocol.

Built for live performance environments, experimental broadcasting, and hybrid media systems.

---

## ✨ Features

* Real-time OMT stream decoding
* Low-latency performance
* Lightweight GUI (Dear ImGui)
* Cross-platform architecture (Windows-first)
* Designed for live media workflows

---

## 🧠 Technology Stack

* C++
* Dear ImGui (GUI)
* SDL2 (windowing & input)
* Open Media Transport (OMT)
  <https://github.com/openmediatransport>
